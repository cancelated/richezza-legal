Terms of Service · Privacy Policy

Overview

This policy describes information Richezza may process to provide Discord bot features. The precise data used depends on which commands and features a server enables.

Before publishing: The bot operator must confirm whether message content, moderation logs, music/Last.fm integrations, or other features collect additional data; update this policy accordingly. Do not publish claims that have not been verified against the running bot.

Information processed

To operate Discord commands and server settings, Richezza may process Discord server (guild) IDs, user IDs, channel IDs, role IDs, command arguments, and configuration values. Its whitelist feature stores server approval information. Certain features may also process messages or other information made available to the Bot through Discord permissions. Data handled by optional integrations depends on those integrations.

How information is used

Information is used to respond to commands, manage server settings and permissions, enforce server eligibility, troubleshoot errors, and maintain Bot functionality. Richezza should not be used to collect information beyond what is needed for enabled features.

Storage and retention

Configuration and whitelist records may be retained while needed to operate the Bot, including after a server removes the Bot unless deleted on request or through an implemented cleanup process. Operational logs and integration data may have different retention periods. Contact us for details about a specific record or deletion request.

Third-party services

Discord provides the platform and associated API data. Optional Bot features may use outside services (for example, music or account-linking services), which may have their own privacy practices. This page should be updated to identify active integrations before publication.

Sharing and security

Data may be transmitted to Discord and to third-party providers needed for enabled Bot features. We take reasonable steps to limit access to stored configuration data, but no system can guarantee absolute security. We do not claim that data is never shared with service providers.

Your choices and deletion requests

Server administrators can disable features or remove the Bot from a server. To request access to or deletion of data associated with a Discord user or server, email wavyahmer@gmail.com with the relevant Discord ID and a description of your request. We may need to verify authority before fulfilling requests, and some data may be retained when legally necessary.

Children and changes

Richezza is intended for users permitted to use Discord under Discord’s age requirements. We may update this policy as features or data practices change; the updated date appears above.

Contact
